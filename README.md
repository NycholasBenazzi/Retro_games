# Atividade Front-end - Retro Games

## Sobre a atividade
Nessa atividade foi realizado uma pratica de Front-end em HTML. A atividade teve como objetivo fazer uma página para uma loja de games retro treinando a pratica dos alunos em HTML com tags ensinadas durante as aulas dadas.

## Tags usadas 
1. li
2. ul
3. strong
4. Table
5. tr
6. em
7. thead

## Tecnologias utilizadas
- Visual Studio Code
- HTML
